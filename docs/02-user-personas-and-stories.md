# 02 User Personas and Stories

## Primary Personas

### Persona A: Daily Learner

- Goal: Build consistent Bible verse memory.
- Need: Quick daily review with simple progress.
- Pain points: Too many setup steps and confusing study tools.

### Persona B: Youth Program Participant

- Goal: Memorize assigned passages for a season.
- Need: Easy package access and chapter-based studies.
- Pain points: Difficult onboarding and no offline support.

### Persona C: Parent or Mentor

- Goal: Guide memorization for a child or group.
- Need: Reliable progress view and simple package management.
- Pain points: Hard to know what is learned versus unlearned.

## Core User Journeys

1. First launch -> open Library -> download package -> open package.
2. Create study -> start verse review -> mark learned/difficult -> exit.
3. Return later -> resume study -> continue from last verse.
4. Open Progress -> inspect package summary -> inspect chapter detail.

## User Stories by Area

### Store and Downloads

1. As a new user, I want to see free packages in Store so I can start quickly.
2. As a user, I want to download a package and see progress so I trust the process.
3. As a user, I want downloaded packages in a separate tab so I can open them easily.
4. As a user, I want to delete a package with confirmation so I can free storage safely.

### Study Creation

1. As a user, I want one-tap chapter studies to start immediately.
2. As a user, I want one-tap section studies for passage-level memorization.
3. As a user, I want custom verse selection with filters so I can target weak areas.

### Study Session

1. As a user, I want a clean card with tap-to-flip so I can self-test recall.
2. As a user, I want to mark verses learned or difficult so review reflects real mastery.
3. As a user, I want optional audio playback so I can memorize by listening.

### Progress and Settings

1. As a user, I want package-level progress so I know overall trajectory.
2. As a user, I want per-verse visual progress to identify gaps.
3. As a user, I want text, theme, and font controls for readability.

## Story Prioritization

P0:
- Download and open free package
- Create and run study session
- Persist verse states and progress

P1:

- Purchase and entitlement sync flows

P2:
